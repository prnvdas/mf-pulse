It compounds today's value and your SIP at one fixed yearly return, with no interruptions, fund switches or SIP changes; the first year counts only the SIPs still to come. 12% is a common long-run planning assumption; 15%, 18% and 22% are optimistic scenarios, and holding 22% for decades would be exceptional.     Reliable updates (optional)

    GitHub's schedule can run late or skip runs. With a token saved in this browser only, Refresh can ask GitHub to run the update right away, and this page will request one itself if market-hours data goes stale. Create a fine-grained token for this repository only with Actions: Read and write (nothing else), then paste it here. Steps are in TRIGGERS.md.

    How this works. AMFI publishes NAV once daily, after close. Pressing refresh prices every stock in each fund's disclosed portfolio, weights the moves, models the untracked tail with the fund's benchmark index, subtracts the day's TER accrual, and infers where NAV lands tonight.
    Read it as a direction, not a settlement figure. Holdings come from monthly AMC disclosures and lag reality. The accuracy panel shows measured error against published NAV — trust that over the headline precision. Nothing here is investment advice.
